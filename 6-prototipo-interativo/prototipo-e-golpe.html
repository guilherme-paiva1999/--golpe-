É Golpe?
Protótipo v0.1 · extensão Chrome
Demonstração interativa

Descubra se um site é golpe antes de digitar a senha.

A extensão lê o endereço da página, consulta listas públicas e dados do domínio, e um modelo de machine learning devolve uma nota de risco de 0 a 100 com os motivos.

Sobre os dados deste protótipo: a lista de bloqueio, o ranking de sites conhecidos e a idade dos domínios são tabelas locais de exemplo, e os pesos do modelo são ilustrativos. A versão real troca isso por PhishTank, URLhaus, Tranco e RDAP, e pesos treinados com dataset público.

    3 · Por que essa nota

    O modelo mostra o que pesou na decisão

    Cada sinal vira um número (feature). O modelo soma os pesos e converte o total em probabilidade. Barras vermelhas empurram para golpe e verdes empurram para seguro.

    Contribuição de cada sinal

    Rode uma análise para ver os sinais.

    Como a nota é calculada

    z = viés + Σ (peso × sinal) p = 1 / (1 + e^-z) nota = p × 100

    Este é o formato de uma regressão logística, o modelo mais simples e explicável para começar. Na versão treinada, os pesos saem de um dataset como PhishTank, UCI Phishing Websites e coletas próprias com sites brasileiros.

    Trocar por Random Forest ou XGBoost melhora a precisão, mas exige gerar a explicação por outros meios (por exemplo, SHAP).

    4 · Arquitetura proposta

    Da página aberta ao alerta

    O cache local evita consultas repetidas. O modelo pode rodar dentro da extensão (privacidade máxima) ou numa API própria (mais poder).

    flowchart LR
  A[Usuário abre uma página] --> B[Content script lê URL e conteúdo]
  B --> C[Service worker da extensão]
  C --> D{Cache local?}
  D -- sim --> H[Veredito]
  D -- não --> E[Listas: PhishTank e URLhaus]
  C --> F[RDAP: idade do domínio]
  C --> T[Ranking Tranco]
  E --> G[Modelo de ML]
  F --> G
  T --> G
  G --> H
  H --> I[Alerta na página e selo no ícone]
  I --> J[Denúncia do usuário]
  J --> K[(Dataset para retreino)]

    Extensão (Manifest V3)

    Interface, leitura da página e cache.

    • content script + service worker
    • popup com a nota e os motivos
    • permissões mínimas para a loja aprovar

    Dados abertos

    Fontes públicas que alimentam o modelo.

    • PhishTank, OpenPhish, URLhaus
    • RDAP para idade do domínio
    • Tranco para ranking de sites legítimos

    Machine learning

    Do simples ao sofisticado.

    • Fase 1: regras + regressão logística
    • Fase 2: XGBoost com features de URL e domínio
    • Fase 3: NLP em português para o texto da página

    Limites a discutir na apresentação: falsos positivos derrubam a confiança, então o limiar precisa de calibração; o histórico de navegação é dado sensível pela LGPD, por isso o desenho prioriza análise local; e golpes mudam rápido, o que exige atualização frequente das listas e retreino do modelo.
